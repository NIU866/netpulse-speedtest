# NetPulse 网络测速

[打开在线测速工具](https://niu866.github.io/netpulse-speedtest/)

点击「开始测速」即可在浏览器中测量下载、上传、HTTP 延迟和抖动。可随时停止，查看每个请求的实测速率，并在同一浏览器回顾最近 12 次完整测试。支持手机、平板和桌面浏览器。

| 模式 | 下载测试数据上限 | 上传测试数据上限 |
| --- | ---: | ---: |
| 轻量 | 8 MB | 2 MB |
| 标准 | 32 MB | 8 MB |

上限按十进制 MB 计算，另有 HTTP、TLS 与网络协议开销。慢速连接可能在到达流量上限之前完成。

## 怎样测量

- 自动模式以空请求探测节点，优先使用 Cloudflare，其次是 LibreSpeed 的东京 A573 和洛杉矶 Clouvider 节点。也可以手动指定。测量开始后，全程使用同一节点，已发送的测试数据不会在别的节点自动重传。端点来自 [Cloudflare 测速项目](https://github.com/cloudflare/speedtest) 和 [LibreSpeed 公共测速节点列表](https://librespeed.org/backend-servers/servers.php)。
- 当所有公网测速 API 都无法连通时，使用当前网页所在服务器提供的 `ping.txt` 和 512 KiB 二进制样本 `sample.bin` 测量延迟、抖动和下载。页面会明确显示仅下载完成，上传留空，这类结果不计入完整历史。每个请求带唯一标识并跳过浏览器缓存。
- 空载阶段先预热一次，再取 6 次或 8 次 HTTP 往返时间的中位数。抖动取相邻往返时间差的绝对值的平均值。
- 下载与上传分别顺序发送大小自适应的数据块。下载会核对实际字节数，上传使用随机生成的字节，等待节点成功响应。最终速率等于成功传输的总比特数除以请求总耗时，以十进制 Mbps 显示。图中的点表示每次请求的平均速率。
- 结果包含 HTTP 请求开销，并受浏览器、Wi-Fi、代理以及节点距离影响。它描述这条具体网络路径上的有效传输速度。
- 页面仅在你点击后开始传输。测速节点会接收连接 IP，网页用浏览器本地存储保存最近结果。清空记录可移除本机历史。

## 在自己的电脑运行

使用 Node.js 20 或更新版本。项目没有第三方依赖。

```sh
npm start
```

打开 `http://127.0.0.1:8080`。默认自动选择测速节点。切换到「本站节点 · 支持上传」可以测试浏览器到这台服务器的网络路径。在服务器本机测「本站节点」得到的是回环连接速度。

如需从局域网内另一台设备测试，将 `HOST` 设为服务器的局域网地址，也可用 `PORT` 指定端口。在另一台设备的浏览器打开对应地址并选择「本站节点」。

```sh
npm test
```

自动化测试通过真实的本机 HTTP 连接验证上行字节确认、下行字节校验、流量上限、取消操作和错误处理。

## GitHub Pages

本仓库可直接从 `main` 分支根目录发布。公开页面使用静态文件，测速流量由浏览器直连选中的节点。可选的 `server.mjs` 在运行 Node.js 的主机上提供同源上传、下载接口。
